# Tab — reference-bound skinned character (candidate)
The original `tabshiftqwerty.jpg` artwork is the design authority, not a prompt to redesign the character. Front has one large eye, one smaller eye, steep eyebrows and gritted-teeth print on an actual box; the left side has upside-down maroon THIS END UP lettering and a downward arrow. The four flaps open around shoulders. No visible conventional face, mouth rig or hair underneath. Slim child wearing a dark short-sleeve bodice and broad asymmetrically draped gray dress, bare shins and dark rounded flats. One arm bent with a hand at waist, the other carries a small brown bear by the ear.
The separate self-contained file `public/assets/characters/Tab_Reference.glb` includes a 20-bone glTF skin, UV-mapped drapery/limbs, two embedded PNG decals, and `Tab_Walk`, `Tab_Idle`, `Tab_Bear_Swing` clips. Generator is `scripts/build_reference_tab.py`. Do not cel-shade Tab as a robot. Existing character code remains the fallback when loading fails.
The asset has been reviewed in standalone render; this feature branch is not an assertion of in-game visual approval. Before merging, inspect the game browser from front and left, check embedded box art orientation and bear hand position, and verify there are no WebGL or animation errors.

T3.2 replaces the solid box core with an open-bottom shell and four thin flaps; see `docs/characters/tab-t32-box.md` for preservation gates and production close-view evidence. This does not grant final model acceptance.
